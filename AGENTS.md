# Glyph

Everything an agent needs to work here is in [`CLAUDE.md`](CLAUDE.md): where to
start, how to verify, and the constraints. This file points at it and copies
nothing, so the two cannot drift.

The one thing that differs for Codex: the `glyph-markup` skill it loads is the
package in [`plugins/glyph-markup/`](plugins/glyph-markup/), listed by
[`.agents/plugins/marketplace.json`](.agents/plugins/marketplace.json). It is
generated by `node scripts/build-skill.js`, and `npm run check` refuses when it
diverges from the engine.
