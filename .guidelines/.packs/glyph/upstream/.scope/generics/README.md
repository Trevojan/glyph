"Order Matrices" are orders that follow conventions to assemble a formulary to be filled by an input pattern, be it from the user or from the AI's model.



An Order Matrix must be object-abscent, though always target one with value and variable definitions.



An Order Matrix may be chained along others, creating a nicknamed folder of a "DRAWING" (Glyph's core workflow). The drawing must have a folder for itself, containing its own pattern of "ORD-NNNN.zip", recognized by a built-in signature.



The Signature let other workflows accept another's ORDs, allowing the engine to chain them all for an otimized output.



Setting signatures for Order Matrices may alter the base behaviour of the Glyph engine and always output a series of pre-setted ORDs following its specification.
